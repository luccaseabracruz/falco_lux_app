# Falco Lux App

Operations platform for bird-control and falconry teams in the Iberian Peninsula (Portugal and Spain): staff attendance and safety, raptor management and weighing, field journal and client reports.

> **Status:** discovery phase (Lean Inception). No application code yet.
> The client's original proposal is treated as a hypothesis, not as fixed requirements.
